Formas de aplicar CSS

O CSS pode ser aplicado de três formas: inline, interno e externo.

CSS inline

É escrito diretamente no atributo style de um elemento HTML. O estilo fica associado àquele elemento.

A repetição de estilos em vários elementos dificulta a manutenção.

CSS interno

É escrito em um bloco style dentro do head do documento HTML. Pode ser utilizado em testes e páginas únicas.

Quando várias páginas precisam do mesmo estilo, repetir o CSS interno aumenta o trabalho de atualização.

CSS externo

É escrito em um arquivo separado com extensão .css. O HTML se conecta a esse arquivo por meio de um elemento link no head.

Essa forma facilita a organização, a manutenção e a reutilização de estilos.
