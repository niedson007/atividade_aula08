O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. É a linguagem responsável pela aparência das páginas web.

Para que serve?

O CSS permite alterar cores, fontes, tamanhos, bordas, espaçamentos e posicionamento dos elementos de uma página.

HTML, CSS e JavaScript

  • HTML organiza a estrutura e o conteúdo.
  • CSS define a apresentação visual.
  • JavaScript permite programar comportamentos e interações.

Separação entre estrutura e aparência

Manter o conteúdo no HTML e os estilos no CSS facilita a organização e a manutenção de um site.
