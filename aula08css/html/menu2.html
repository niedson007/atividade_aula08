Organizando a página com DIVs

A DIV é um elemento de bloco usado para agrupar textos, imagens e outros elementos do HTML. Ela não possui significado semântico próprio.

Organização da página

  • Cabeçalho: apresenta o título e a identificação do site.
  • Menu: reúne os links de navegação.
  • Conteúdo principal: apresenta as informações da página.
  • Rodapé: apresenta informações complementares.

DIV e CSS

Uma DIV não possui aparência visual própria. O CSS pode definir sua cor de fundo, largura, bordas e espaçamentos.

Elementos semânticos

Elementos como header, nav, main e footer identificam a função de cada parte da página. A DIV serve para agrupamentos que não precisam de um significado específico.
